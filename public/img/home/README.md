# Главная — изображения

Пути жёстко заданы в `components/home/home-data.js`.
Положите файлы ровно с этими именами — код менять не нужно.

## Hero-слайдер (4 слайда)

Каждый слайд — **одна готовая композиция**, выгруженная из Figma целиком:
размытый фон `blur(5px)`, затемнение 20% и вырезанный человек уже сведены в один файл.
Код ничего не размывает и не затемняет — иначе размытие наложится дважды.

Нужны два файла на слайд: десктоп и мобильный (у них разная компоновка кадра).

| Файл | Размер (точно) | Слайд |
|---|---|---|
| `hero/models-bg.png` | 1920 × 1080 | «Модели», десктоп |
| `hero/models-bg-mobile.png` | 320 × 824 | «Модели», мобильный |
| `hero/photographers-bg.png` | 1920 × 1080 | «Фотографы», десктоп |
| `hero/photographers-bg-mobile.png` | 320 × 824 | «Фотографы», мобильный |
| `hero/videographers-bg.png` | 1920 × 1080 | «Видеографы», десктоп |
| `hero/videographers-bg-mobile.png` | 320 × 824 | «Видеографы», мобильный |
| `hero/venues-bg.png` | 1920 × 1080 | «Площадки», десктоп |
| `hero/venues-bg-mobile.png` | 320 × 824 | «Площадки», мобильный |

Как выгружать из Figma: выделить слой-композицию слайда (без текста и кнопок интерфейса)
и экспортировать PNG в 1× — размеры совпадут с таблицей.

Изображение выводится с `object-cover object-center`, поэтому на экранах шире 1920
кадр равномерно масштабируется, а на более узких — подрезается по краям.
