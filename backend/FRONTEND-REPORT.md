## Мелочь: `/customer/applications` отдаёт голый массив

Единственный список, который не в форме `{ items, meta }`:

```
GET /customer/applications          → 200  [ … ]          (массив)
GET /agency/applications            → 200  { items, meta }
GET /performer/invites              → 200  { items, meta }
GET /customer/projects              → 200  { items, meta }
```

Мы поддерживаем оба варианта, ничего не падает. Но пагинации у этого списка
из-за отсутствия `meta.total` нет — если откликов станет больше страницы,
понадобится `{ items, meta }`.
